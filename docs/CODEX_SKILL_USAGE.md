# 앱 개발용 AGENTS.md 관리 스킬

## 목적

`maintaining-app-agents`는 앱 개발 저장소의 `AGENTS.md`를 항상 읽는 최소 지침과 작업별 문서 라우터로 유지하기 위한 개인 Codex 스킬이다. 제품·기술 상세를 없애는 것이 아니라 PRD, TRD, 결정 기록, 작업 목록 등 적절한 정본으로 무손실 이동해 시작 컨텍스트를 줄인다.

## 설치 위치

Codex 공식 문서의 사용자 범위 경로에 따라 다음 위치에 설치한다.

`C:\Users\차명근\.agents\skills\maintaining-app-agents\SKILL.md`

프로젝트에 보관한 원본은 `skills/maintaining-app-agents/`다. 개인 스킬 폴더의 복사본을 변경했다면 두 위치가 달라지지 않도록 원본에도 같은 변경을 반영한다.

## 다른 Codex 작업에서 사용하기

새 앱 프로젝트에서 가장 확실한 호출 방법은 요청에 스킬 이름을 직접 쓰는 것이다.

```text
$maintaining-app-agents 이 앱 저장소에 최소 AGENTS.md와 문서 라우팅 구조를 만들어줘.
```

기존 파일이 커진 경우:

```text
$maintaining-app-agents 현재 AGENTS.md를 감사하고, 상세 내용을 잃지 않게 관련 문서로 옮긴 뒤 최소 라우터로 정리해줘.
```

스킬 설명과 요청이 일치하면 Codex가 암묵적으로 선택할 수도 있지만, 반드시 적용해야 하는 작업에서는 `$maintaining-app-agents`로 명시 호출한다. 새로 설치한 스킬이 목록에 보이지 않으면 Codex를 재시작한다.

## 적용 범위

- 이 개인 스킬은 다른 저장소에서도 발견된다.
- 스킬은 관련 요청에 사용할 작업법이며 모든 대화에 전문이 자동 주입되는 전역 규칙이 아니다.
- 한 번 스킬로 프로젝트 루트의 `AGENTS.md`를 만들면 이후 그 저장소의 Codex 작업은 해당 프로젝트 지침을 자동으로 읽는다.
- 모든 작업에 강제 적용하려고 전역 `~/.codex/AGENTS.md`에 긴 지침을 복제하지 않는다. 정말 필요한 경우에도 “앱 개발 저장소의 AGENTS.md 생성·정리에는 `$maintaining-app-agents`를 사용한다” 정도의 짧은 한 줄만 선택적으로 둔다.

## 현재 프로젝트 반영

현재 냉톡 저장소의 `AGENTS.md`는 이미 이 패턴으로 정리되어 있다. 이후 새 기능·정책·기술 상세는 적합한 기존 문서에 기록하고, 맞는 문서가 없을 때만 새 문서를 만든 뒤 필요하면 `AGENTS.md` 라우팅 표에 경로 한 줄을 추가한다.

## 검증 기록

- 스킬 작성 전 독립 시나리오 3개로 상세 보존, 새 주제 배치, monorepo 계층 판단을 확인했다.
- 기존 프로젝트 지침 덕분에 상세 분리 원칙은 대체로 지켜졌지만, Codex의 instruction chain과 검증 복잡도에서 편차가 확인됐다.
- 스킬은 공식 계층 순서, 단일 정본, 최소 라우팅, 무손실 이동, 필요한 수준의 검증을 명시한다.
