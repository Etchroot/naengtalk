# 구매내역 샘플 R1~R5 판독 기준

## 문서의 상태

이 문서는 2026-09-09에 제공된 다섯 장의 캡처를 사람이 화면으로 확인해 만든 **사전 정답 기준**이다. 아래 `인식 원문`은 주문번호·결제·주소 같은 개인정보를 제외하고 화면에 보이는 상품 텍스트를 옮긴 것이며, `서비스 등록 예상`은 냉톡의 결정적 변환 규칙을 적용한 결과다.

실제 OpenAI 비전 API 출력은 `OPENAI_API_KEY` secret과 `purchase-ocr` Edge Function 배포 후 앱에서 R1~R5를 각각 실행해 비교한다. 따라서 이 문서는 모델 실행 결과를 가장한 자료가 아니며, 실측 결과가 생기면 `실제 API 결과` 절을 추가해 차이를 기록한다.

등록 기준일은 데모 실행일인 `2026-09-09`로 통일했다. 캡처에 과거 주문일이 보이더라도 심사용 샘플 재고가 즉시 만료되지 않도록, MVP 데모는 캡처 날짜 대신 등록 시점을 기준으로 권장 소진일을 계산한다.

## API 실측 시 확인할 항목

1. 상품 이미지가 아니라 화면 텍스트만 근거로 답했는가.
2. 키친타올과 잘린 가격 행을 재고에서 제외했는가.
3. `300g 2개`, `210g 12입`을 총량으로 환산했는가.
4. R2의 중복 가능 행과 R3의 중량 없는 너겟을 `확인 필요`로 남겼는가.
5. 주소·주문번호·결제정보를 OCR 원문과 결과에서 제거했는가.
6. 등록 확정 전 DB가 바뀌지 않고, 확정 후 현재 게스트 소유 재고에만 추가되는가.
